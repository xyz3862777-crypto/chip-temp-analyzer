# CHIP Temp & Power Analyzer

Interactive single-page estimator based on the supplied CHIP temperature and power analysis slides.

Open `index.html` in a browser. Change panel loading, resolution, SR, resistance, PWRC, DBC, and calibration values to update the temperature and power curves live.

The model uses the slide-derived relationship `T(CHIP Temp) ≈ X + Y × P` and is intended for front-end trend analysis. Calibrate X and Y with measured data before sign-off use.
